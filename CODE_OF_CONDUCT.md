# Code of conduct

## The short version

Be decent. Assume the other person is trying to help. Argue about the code, not
about the person writing it.

## Expected

- Give feedback on the change, with a reason and, where you can, a suggestion.
- Accept that "no" is a legitimate answer to a feature request, and that
  maintainers owe you an explanation rather than an implementation.
- Respect that people contribute in their own time.

## Not accepted

Harassment, personal attacks, discriminatory language, sustained disruption, or
publishing someone's private information.

## Enforcement

Report a problem to the maintainer through a private GitHub security advisory or
by email on the maintainer's profile. Reports are handled confidentially.
Responses range from a warning to a permanent ban, depending on severity.

This is adapted from the spirit of the Contributor Covenant, kept short on
purpose so that it is actually read.
